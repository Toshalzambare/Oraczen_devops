---
ACTION : Refactored app/Dockerfile to use Python venv multi-stage pattern instead of --prefix approach.
         Stage 1 (builder): creates /venv and installs all deps into it via /venv/bin/pip.
         Stage 2 (runtime): copies /venv from builder, sets ENV PATH="/venv/bin:$PATH", runs as root (default).
         Removed the addgroup/adduser/chown/USER lines entirely — simpler image.

         (runAsNonRoot: true / runAsUser: 1000 / fsGroup: 1000) since those required a dedicated
         non-root user to exist inside the image, which we no longer create.
